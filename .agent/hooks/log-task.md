# Hook: Log Task（タスク完了時の記録）

> トリガー: 作業を検証し、commit / push した直後。
> 進捗の正本: `docs/task-list.md`。実行ログの新規ファイルは作らない。

1. タスクの状態・検証結果（PASS / FAIL / skip / 未実行）・コミット SHA・PR 番号・残事項を `docs/task-list.md` に記録する。記録後の変更も検証・commit / push する。
2. 設計判断は `docs/adr/`、再利用する手順は `.agent/skills/` または `.agent/rules/` に置き、索引を同期する。作業用のログ・一時ファイルは Git に含めない。
3. 作業の所在は Git の SHA と PR 番号で示し、セッション固有のブランチ名は文書に固定しない。
4. ユーザーへの報告では実施内容・自分で追加した作業・検証・未解決・未実施を区別する。

# 品質ツールと Git/PR の読み取り専用レポート

> Date: 2026-10-25 / Tasks: TOOLING-1〜3

## 実行と反復

1. actionlint 1.7.12 は公開 GitHub リリース資産の SHA-256 を記録したが、本環境は資産配信先への接続で EOF。CI に固定版・チェックサム検査と異常 fixture を追加し、実 CI での検証を待つ。
2. zizmor 1.31.1 の初回監査は Actions の unpinned-uses、artipacked、Dependabot cooldown、cache-poisoning を報告。SHA 固定、checkout の認証情報保存停止、release のキャッシュ停止等で修正。オフラインの正常例 exit 0、template-injection の負例 exit 14。
3. Knip 6.43.0 は oxc-parser の raw transfer の仮想バッファ確保で失敗したため `KNIP_DISABLE_RAW_TRANSFER=1` に固定。限定的な例外を説明付きで設定し、根の監査 exit 0、独立した未使用ファイル fixture の exit 1 を確認。OSV は定期・手動の `bun.lock` 全体走査を設定したが DB 通信と実ワークフローは未検証。
4. simple-git、Octokit、conventional-commits-parser による読み取り専用レポートを追加。一時 Git リポジトリと API モックで pass/fail/unknown を検査。実 PR API は未検証。`bun run check` は 7 ゲート、48 pass / 2 skip / 716 assertions。次は CI 実測で actionlint と OSV の未確認事項を調査し、失敗を隠さず修正する。

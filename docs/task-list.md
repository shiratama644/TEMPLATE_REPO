# タスクリスト（派生プロジェクト用）

> これは新規プロジェクトの空の進捗表です。テンプレート本体を開発したときのタスクは引き継ぎません。
> 初期設定時に [`project-init`](../.agent/skills/project-init/SKILL.md) を使い、利用者が承認した最初のタスクを登録してください。

## 運用ルール

1. **本ファイルを進捗の唯一の正本**にします。チャットや AI の完了報告と矛盾したら本ファイルを確認します。
2. 進行中のタスクは原則 1 件。ID はプロジェクト内で一意にし、一度使った ID を再利用しません。
3. 中止したタスクは消さずに「対象外」とし、理由を残します。完了はテスト結果・成果物・コミット SHA などの証拠で判定します。
4. 詳細な計画が必要なら [`planning/_TEMPLATE.md`](./planning/_TEMPLATE.md) を使います。実環境で未検証なら「完了」ではなく「実環境検証待ち」にします。

**状態**: 未着手 / 調査中 / 実装中 / ローカル検証済み / 実環境検証待ち / 完了 / 保留 / 対象外。

## 未完了サマリー

なし。最初のタスクを登録したら、ここに ID・状態・次に行うことを記載してください。

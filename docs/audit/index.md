# audit/ — 差分・バグ監査

> **このフォルダの役割**: 「計画と実装の差分」と「発見したバグ」の監査記録を置く場所。
> 記録は**時点記録（当時の事実）**として扱い、過去の記録は書き換えない。

## ここに置くもの

| ファイル | 役割 |
| :--- | :--- |
| `diff-{context}.md` | 計画書 vs 実装の差分レポート（意図的な変更とその判断理由） |
| `issues-{context}.md` | バグ・潜在的不具合のリスト（発見経緯・影響・修正状況） |

## 書き方

- **差分レポート**: 計画書のどの項目が、なぜ、どう変わったかを書く。意図的な差分は「判断理由」を残す。
- **バグリスト**: ID・概要・影響・状態（未修正 / 修正済み）を表形式で管理する。

## 運用ルール

- 命名は `diff-{context}.md` / `issues-{context}.md`。
- **過去の監査記録は時点記録のため書き換えない**（一括置換・リネームの対象外。AGENTS.md §8.5 参照）。
- 修正・追記が必要な場合は新規レポートに書く。

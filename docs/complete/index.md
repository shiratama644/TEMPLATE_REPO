# complete/ — 完了レポート

> **このフォルダの役割**: タスク・マイルストーン完了時の事後報告書を置く場所。
> 進捗の正本は `docs/task-list.md`。ここは「何を・どのように・どんな結果で終えたか」の記録。

## ここに置くもの

| ファイル | 役割 |
| :--- | :--- |
| `{TOPIC}_COMPLETE.md` | タスク・マイルストーン完了時のレポート |

## 完了レポートに書くこと

- 完了条件（DoD）の達成状況
- 実施したサブタスクの一覧
- メトリクス（テスト件数 / カバレッジ / 実測値など）
- コミット SHA・PR・CI run 等の証拠
- 残課題・持ち越し事項（あれば）

## 運用ルール

- 作成タイミング: タスク（計画書単位）完了時。小さなタスクは `docs/task-list.md` の記録で済ませてよい。
- 命名は `{TOPIC}_COMPLETE.md`。
- 完了レポートは時点記録。後から追記・修正する場合はセクションを分けて追記する。

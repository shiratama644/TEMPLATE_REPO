# ops/ — 運用ドキュメント

> **このフォルダの役割**: デプロイ・CI・本番運用の手順書を置く場所。
> 変更頻度は低く、実際にデプロイ・運用する際に参照する。

## ここに置くもの

| ファイル | 役割 |
| :--- | :--- |
| `DEPLOY.md` | デプロイ手順（環境変数・チェックリスト・検証項目） |
| `CI_SETUP.md` | CI のセットアップ・動作確認手順 |
| `CI_WORKFLOW.yml` 等 | CI ワークフロー定義の保管（リポジトリ内の配置に制約がある場合に利用） |

## 運用ルール

- 命名は大文字スネークケース（例: `DEPLOY.md` / `CI_SETUP.md`）。
- 手順書は「初めての人が読んで実行できる」粒度で書く（コマンドと期待結果を明記）。
- 手順を変更したら実際に実行して検証してから反映する。

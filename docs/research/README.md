# docs/research — 調査結果

競合・関連技術・手法などの調査結果を置く場所です。調査の結論を仕様へ採用する場合は、`../arch/` へ反映してから作業に入ります。

## 書き方

- ファイル名: `<TOPIC>_RESEARCH.md`（例: `pricing-models_RESEARCH.md`）
- 含めるもの: 調査の目的、調べ方（情報源と日付）、結論、採否の判断、未確認の点
- 情報源には URL と確認日を書く。推測と事実を分けて書く（`AGENTS.md §7.3`）。

## 構成

```
research/
├── README.md          ← 本ファイル（調査一覧）
└── <TOPIC>_RESEARCH.md   # 個別の調査
```

# 設計判断（ADR）

ここには利用者のプロジェクトで新たに採用した判断を記録します。テンプレート本体の開発判断は引き継ぎません。

- 書式と承認手順は [architecture-decision-records](../../.agent/skills/architecture-decision-records/SKILL.md) を参照します。
- 1 判断 1 ファイルとし、`NNNN-<kebab-case-title>.md` で番号を付けます（最初は `0001`）。
- 既存の判断を変えるときは古い ADR を改変せず、新しい ADR に置き換え理由を記録します。

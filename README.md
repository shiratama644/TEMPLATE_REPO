# TEMPLATE_REPO

AI Agent によるソフトウェア開発を規律立てて進めるための**テンプレートリポジトリ**です。

GitHub の「Use this template」から新しいリポジトリを作成し、各プロジェクトで
カスタマイズして使うことを想定しています。

## 含まれるもの

| パス | 役割 |
| :--- | :--- |
| `AGENTS.md` | AI Agent が必ず遵守すべき開発規約（ワークフロー / テスト・品質保証 / Git 運用 / コミュニケーション規約 / 記憶システム）。**汎用規約**と**プロジェクト固有の規約（§6）**に分かれている |
| `.agent/hooks/` | トリガー別の定型手順（タスク開始時の現状把握 / commit 直前の検証 / タスク完了時のログ記録 / サンドボックス再構築からの復旧） |
| `.agent/skills/` | コードベース知識（事実・仕様・暗黙了解）の置き場。**最初は空**。学習した知識をここに蓄積する |
| `.agent/logs/` | タスク実行ログの置き場。**最初は空**。タスク完了ごとに 4 セクション形式で追記する |
| `docs/` | ドキュメント一式。`docs/README.md`（目次・命名規則）/ `docs/task-list.md`（タスク管理の正本）/ `planning/` `complete/` `audit/` `ops/`（各フォルダに `index.md` で役割を説明） |
| `LICENSE` | MIT License |

## 使い方

1. GitHub の「Use this template」で新しいリポジトリを作成する
2. 新しいリポジトリのセットアップを行い、`AGENTS.md` の「§6 プロジェクト固有の遵守事項」にそのプロジェクト固有のルールを追記する
   - 技術スタック・バージョン方針（§6.1）
   - 実行環境の制約（Sandbox 制約など、§6.2）
   - フレームワーク / Lint / UI の実装ルール（§6.4〜6.6）
   - ドキュメント運用（§6.7）
3. 開発を進めながら、学んだコードベース知識を `.agent/skills/` に、実行記録を `.agent/logs/` に蓄積していく
4. タスクの計画・進捗管理は `docs/task-list.md`（正本）+ `docs/planning/`（計画書テンプレート `_TEMPLATE.md` 準拠）で行う。ドキュメントの書き方・命名規則は `docs/README.md` を参照

## 仕組みの概要

- **AGENTS.md** = 「どう作業するか」の規約（常に正）
- **skills/** = 「このコードベースがどう出来ているか」の事実・仕様（深掘り用）
- **hooks/** = 「いつ・どの手順を実行するか」のトリガー別チェックリスト
- **logs/** = 「いつ・何が起きたか」の実行記録（追加のみ・書き換え禁止）

詳細は [`AGENTS.md`](AGENTS.md) §8（エージェント記憶システム）を参照してください。

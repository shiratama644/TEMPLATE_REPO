# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a tool to manage versioning and changelogs.

If you’re using changesets to manage your versioning, please refer to https://github.com/changesets/changesets/blob/main/docs/intro-to-using-changesets.md

We have customized the config for this template repository:

- `privatePackages.version: true` — private packages still get CHANGELOG updates (useful for template tracking)
- `privatePackages.tag: false` — no git tags for private packages
- `changelog: @changesets/changelog-github` — GitHub-friendly changelog with PR links
- `baseBranch: main` — changesets are compared against main

## Quick Start

```bash
# Create a changeset (describe your change)
pnpm changeset

# Version packages and update CHANGELOG
pnpm changeset:version

# Publish (if public package)
pnpm changeset:publish
```

See `CONTRIBUTING.md` for the full release flow.
